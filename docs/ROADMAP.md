# خارطة الطريق

## المرحلة 1: إصلاحات منصة الويب (من تقرير الاختبار)
1. تصحيح بريد الدعم في صفحة التواصل (support@payerbee1.com ← support@beeplayer1.com).
2. عرض الصفحات العامة بدون انتظار /auth/me، وإضافة robots.txt و sitemap.xml و favicon و manifest.
3. إزالة console.log من الإنتاج وضبط كاش HTML.
4. تشديد CSP وإخفاء ترويسات الإصدارات.
5. إصلاح الأخطاء الإملائية والترجمة في الأسعار والفوتر.

## المرحلة 2: الحزمة المشتركة
- عميل API موحد، ومحلل M3U/M3U8، ومحلل EPG (XMLTV)، وملفات الترجمة.

## المرحلة 3: المشغلات
- مشغل ويب حقيقي في بوابة العميل باستخدام hls.js.
- تطبيق Android Box (أولوية لأنه الأكثر استخداماً في IPTV).
- تطبيق الجوال (Android و iOS) ثم Apple TV.
- تطبيقا LG webOS و Samsung Tizen ونشرهما في متجريهما.
