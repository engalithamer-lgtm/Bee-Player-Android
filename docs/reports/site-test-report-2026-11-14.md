# تقرير اختبار موقع Bee Player (beeplayer1.com)
تاريخ الاختبار: 14 نوفمبر 2026. الاختبار غير تخريبي: لم يُرسل أي نموذج تواصل، ومحاولة دخول واحدة فقط ببيانات وهمية.

## ملخص
الموقع مبني بـ Next.js (App Router) على Nginx، والواجهة الخلفية API على api.beeplayer1.com (يبدو NestJS). الموقع موقع تسويقي + لوحات (مدير، موزع، عميل)، ولا يوجد مشغل M3U/M3U8 فعلي على الويب: صفحة Demo عرض شكلي فقط، والتشغيل الفعلي في التطبيقات.

## مشكلة حرجة
> **تصحيح بعد المراجعة:** كنت قد سجلت أن /login و /register فارغتان وأن /admin و /reseller تنهاران. المستخدم جرّب صفحة البائعين من متصفحه وهي تعمل. ملفات JS نفسها ترجع 200 عند طلبها مباشرة، والخطأ 404 ظهر فقط في متصفح الاختبار داخل بيئتي (عبر بروكسي الشبكة)، وانهيار /admin و /reseller سببه على الأغلب نفس الخطأ حين تحاول التحويل لصفحة الدخول. لذلك أُلغيت هاتان الملاحظتان. وأُلغيت أيضاً ملاحظة "عدم ضغط ملفات JS" لأن الفحص الأدق أثبت أن gzip مفعّل.

1. **بريد الدعم في صفحة التواصل خاطئ:** `support@payerbee1.com` — النطاق payerbee1.com غير موجود (لا DNS)، فكل رسائل العملاء تضيع. الصحيح غالباً support@beeplayer1.com.

3. **سجلات تصحيح (console.log) في الإنتاج:** كل طلب API يطبع الرابط والهيدرز والردود في الكونسول، مع خطأ 401 أحمر في كل صفحة. يجب إزالتها.
4. **كاش HTML لمدة سنة** (`s-maxage=31536000`) قد يُبقي نسخاً قديمة بعد النشر ويسبب طلب ملفات JS محذوفة.
5. **SEO:** لا يوجد robots.txt ولا sitemap.xml ولا favicon.ico ولا manifest (كلها 404). صفحة /pricing ترجع 404 مع أن الأسعار في الرئيسية (#pricing).

## الأمان
- الإيجابي: HTTPS مع تحويل من http و www، وHSTS، وX-Frame-Options، وnosniff. الـ API لا يقبل CORS من نطاقات غريبة، ولا توجد source maps مكشوفة.
- للتحسين: سياسة CSP شكلية (`default-src 'self' http: https: data: blob: 'unsafe-inline'` تسمح بأي مصدر). HSTS بدون includeSubDomains/preload. ترويسة `X-Powered-By: Next.js` و `Server: nginx/1.26.3 (Ubuntu)` تكشف الإصدارات. ترويسة X-XSS-Protection قديمة ويمكن حذفها. جذر الـ API يرد "Hello World!".

## المحتوى والواجهة
- أخطاء إملائية في الأسعار: "1 MONTHE"، "3 MONTHES"، "6 MONTHES".
- في الوضع الإنجليزي تظهر أسماء باقات الكريديت بالعربية ("حزمة الكريديت الصغيرة")، ومحتوى العرض التوضيحي بالعربية.
- الفوتر: © 2025، ورابط "Privacy Policy (Korean)" يبدو غير مقصود.
- تبديل اللغة يعمل جيداً (lang=ar و dir=rtl)، لكن عنوان الصفحة لا يتغير للعربية.
- نصوص الإحصائيات أسفل الهيرو (Live channels…) تباينها ضعيف فوق الصورة.
- عرض الجوال سليم: لا يوجد تمرير أفقي، والقائمة تتحول لزر همبرغر.

## ما يعمل جيداً
الرئيسية، Features، Demo، Downloads، Contact، About، Privacy، وصفحة دخول العميل /customer/login (تعرض "Invalid username or password" بشكل صحيح، وتدعم الدخول بـ MAC + key)، وتبديل الثيم واللغة.

## أولويات التطوير المقترحة
1. تصحيح بريد الدعم.
2. عرض الصفحات العامة بدون انتظار /auth/me + robots.txt + sitemap.xml + favicon.
3. إزالة console.log، وضبط الكاش.
4. تشديد CSP وإخفاء ترويسات الإصدارات.
5. إصلاح الأخطاء الإملائية والترجمة.
6. (ميزة) مشغل ويب حقيقي لروابط M3U/M3U8 في بوابة العميل باستخدام hls.js، يقرأ قائمة القنوات ويعرض EPG.
